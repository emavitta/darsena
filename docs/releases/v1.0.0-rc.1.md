# Darsena 1.0.0-rc.1

First release candidate for macOS, with separate native downloads for Apple Silicon
and Intel. Both builds are Developer ID signed, notarized by Apple, and verified
with Gatekeeper. This is a pre-release for real-project testing before 1.0 stable.

## Download

- Apple Silicon (M-series): `Darsena-1.0.0-rc.1-arm64.dmg`
- Intel: `Darsena-1.0.0-rc.1-x64.dmg`
- ZIP alternatives, SHA-256 checksums and build manifests are included for each architecture.

Drag Darsena into Applications. Quit the previous version before replacing it;
saved projects, favorites and settings remain in the existing application data folder.

## Included

- Git worktree discovery, search and navigation, with branch/status visibility and guarded Git actions.
- Relative folder shortcuts and monorepo workspace folder discovery.
- Task discovery, favorites, custom commands and configurable worktree preparation.
- A shared activity dock with live output, clickable URLs, explicit run status and stop-all controls.
- Android variant/device selection, build/install/launch, ADB actions and app Logcat.
- Authenticated local MCP access, task/run inspection and favorites-based execution permissions for shared projects.
- GitHub release update checks, Nuxt UI tooltips and notifications.

## RC scope

macOS only; no Windows/Linux installer, Git diff viewer or interactive terminal.
Update installation remains manual. Signing does not install project toolchains.
Please report installation/upgrade issues and problems with worktree selection,
task lifecycle, Android or MCP. An issue is not required before opening a PR.
