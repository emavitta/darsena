# Darsena 1.0.0-rc.2

Second macOS release candidate, signed with Developer ID and notarized by Apple.

- **Apple Silicon:** `Darsena-1.0.0-rc.2-arm64.dmg`
- **Intel:** `Darsena-1.0.0-rc.2-x64.dmg`

ZIP packages, architecture-specific checksums and build manifests are also attached.

## Changes since RC1

- Align worktree preparation and task lists with folder shortcuts across the available width.
- Add collapsible environment diagnostics for executable paths and Android platform-tools.
- Remember the last Android variant and device per project folder across worktrees. Missing choices require explicit replacement.
- Remove obsolete design experiments and unused images from the repository and app package.

Quit Darsena completely before replacing it in Applications. Settings and projects are preserved. This release still uses manual installation; in-app installation is being developed separately.
