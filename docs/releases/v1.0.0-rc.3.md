# Darsena 1.0.0-rc.3

- **Apple Silicon:** `Darsena-1.0.0-rc.3-arm64.dmg`
- **Intel:** `Darsena-1.0.0-rc.3-x64.dmg`

## Changes since RC2

- Download future updates inside Darsena and install them with an explicit restart. Installation is blocked while tasks are active.
- Harden desktop permissions and update verification, and patch vulnerable build dependencies.
- Introduce a seven-day waiting period for routine dependency updates.
- Simplify the user guide and installation instructions.

Install RC3 once using the DMG: quit Darsena completely, then replace it in Applications. Projects and settings are preserved. RC2 does not support in-app installation; RC3 enables it for subsequent releases. End-to-end updating between published releases is still being validated during this release candidate cycle.

ZIP packages, checksums and build manifests are also available below.
