First Windows preview, alongside the macOS Apple Silicon build.

## Downloads

- **Windows 10/11 x64:** `Darsena-0.2.0-windows-x64.exe` is the installer. The ZIP contains the same application for manual extraction.
- **macOS Apple Silicon:** open the DMG and drag Darsena into Applications, or extract the Mac ZIP.
- `SHA256SUMS-*.txt` verifies the downloads; `build-*.json` records the source commit and target.

Both builds are unsigned; macOS is not notarized. Gatekeeper or Windows SmartScreen may show a warning. This is an early preview.

## Included

- Git worktree browsing, project favorites and folder shortcuts.
- Open folders in VS Code, a terminal or Android Studio.
- npm/pnpm/Yarn/Bun scripts, Gradle tasks and custom commands, including PowerShell scripts on Windows.
- Task logs, declared-port conflicts and process supervision across worktrees.
- Windows Job Objects keep task descendants together; Stop and Quit terminate the managed job. A task remains active if its initial command exits while children are still running.
- Closing the window keeps tasks running. Reopen from the Dock on macOS or the notification-area icon on Windows; use Quit to stop tasks and exit.

## Windows preview scope

Use local Windows repositories with Git for Windows installed. Install the toolchains required by your projects and restart Darsena after changing PATH. VS Code and Android Studio use their standard install locations or an executable chosen in Preferences. The terminal defaults to Windows Terminal, with PowerShell as a fallback.

Windows Stop forcefully terminates the managed job; it does not emulate Unix SIGTERM. Gradle discovery and generated Gradle tasks use `--no-daemon` on Windows to avoid creating a persistent daemon within a task. Existing external services are independent. Windows shows external listening ports, but cannot reliably infer arbitrary external processes' working folders. WSL repositories and services are outside this preview's scope.

Git worktree selection does not check out or change a branch. Darsena does not install project dependencies or create/delete Git worktrees.

## Validation

The build workflow runs TypeScript checks and backend tests on macOS and Windows, including literal command arguments, Gradle wrapper selection, child-process ownership and stop/quit cleanup. Desktop tests run against the packaged Mac application and the installed Windows application, using disposable repositories and isolated settings. Manual testing with your own project and installed IDEs is still useful for this Windows preview.
