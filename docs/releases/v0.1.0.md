First public preview of Darsena for **macOS on Apple Silicon**.

## Downloads

- **DMG:** open it and drag Darsena into Applications.
- **ZIP:** extract it to get the same Darsena application.
- **SHA256SUMS-macos-arm64.txt:** checksums for both downloads.
- **build-macos-arm64.json:** version, target and exact source commit.

This preview is unsigned and not notarized. macOS may show a security warning when opening it.

## Included

- Browse Git worktrees across saved and favorite projects.
- Open any saved folder shortcut in VS Code, Terminal or Android Studio.
- Run npm/pnpm/Yarn/Bun scripts, loaded Gradle tasks and custom commands.
- See task status, logs and listening ports across worktrees; stop or transfer a task with a declared port conflict.
- Close the window while keeping tasks running; Quit stops managed tasks before exiting.
- Remove projects from Darsena with a clear confirmation, preserving repository files and Git worktrees.
- A Milan-inspired identity, with the Darsena illustration in Welcome and About.

## Scope and validation

Install Git and the toolchains required by your projects separately. Darsena does not install project dependencies, create/delete Git worktrees or change branches when you select a worktree.

The GitHub build checks types and tests real Git repositories, filesystem boundaries and process cleanup. Desktop tests run against the packaged application with disposable repositories and isolated settings, including task execution, port conflicts, window close, Quit and project removal.

Windows is deferred. Its work in progress is preserved in `feat/windows-preview`; this release contains macOS downloads only.
