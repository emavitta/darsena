# Darsena 1.0.0-rc.4

This release candidate validates in-app updating from RC3. Application behavior and dependency versions are unchanged from RC3.

In RC3, open About, check for updates, and download the update inside Darsena. Stop active tasks before choosing Install and restart. Your saved projects and settings are preserved.

- **Apple Silicon:** `Darsena-1.0.0-rc.4-arm64.dmg`
- **Intel:** `Darsena-1.0.0-rc.4-x64.dmg`

Manual DMG downloads, ZIP packages, checksums and build manifests are available as alternatives. In-app installation requires the official signed RC3 installed in Applications.
