# Darsena v0.1.3

- Follow Android Logcat from Activity after a deployment: app filtering, search, severity, export and sampled process state. Collection follows process restarts and stops independently of the device app.
- MCP adds run inspection, bounded completion waiting and Logcat start/read/stop tools for shared projects. Copied HTTP configuration now includes its transport type.
- Compact task lists show tool icons once per folder, repeating them on individual tasks only for mixed groups.
- Fix story scrolling so every landmark can become selected.

## Install

Download the Apple Silicon macOS DMG, open it and move Darsena to Applications.
This preview is ad-hoc signed, not Apple-notarized. Gatekeeper may block downloaded copies; see the README for installation guidance.

No Windows/Intel Mac installer or automatic in-app updater is included. Logcat observations are not an application health guarantee. Android build/install and destructive ADB actions remain unavailable through MCP.
