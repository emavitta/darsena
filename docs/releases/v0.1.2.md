Darsena preview for **macOS on Apple Silicon**.

## Changes

- Fix Android task and variant discovery when Gradle configuration cache is enabled. Only the temporary discovery invocation disables the cache; normal builds retain project settings.
- Use **Sync Gradle** to load or refresh tasks and Android variants.
- Add **ADB actions** inside Run on Android: start, stop, restart, clear app data and uninstall. Select the installed application ID explicitly. Operations target the selected device and Android user; clear/uninstall require confirmation.
- Record ADB operations in Activity and distinguish cancellation from stopping the installed app. Device operations share the deployment conflict guard.
- Prevent local desktop tests and preview scripts from stealing keyboard focus by default. Interactive desktop tests run in GitHub Actions.

## Downloads and installation

Open the DMG and drag Darsena into Applications, or extract the ZIP. Quit the existing app before replacing it. Saved projects and settings are preserved.

The app is **ad-hoc signed, not Developer ID signed or notarized**. Signature integrity is verified in the app, DMG and ZIP; macOS may still warn about or block downloaded apps.

The checksum file verifies both downloads; the build manifest records the exact source commit.

## Validation

Backend tests, type checks and packaged desktop smoke tests run on GitHub Actions. Gradle's original cache error was also reproduced with real Gradle 9.7.1 before verifying the fix. ADB actions were tested with a simulated SDK, not a physical device.

No Windows/Intel Mac installer or automatic in-app updater is included. ADB actions are not exposed through MCP.
