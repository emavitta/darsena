Darsena preview for **macOS on Apple Silicon**, including the work since v0.1.0.

## What's new

- Collapsible project sidebar, a full-width Activity drawer and clearer running/history states, branch names and worktree paths.
- Global worktree search and task lists grouped into collapsible folder sections, with compact color tool logos and Nuxt UI controls.
- Git upstream and ahead/behind status, explicit fetch, fast-forward-only pull and searchable local/remote branches with links to their worktrees. Selecting a worktree does not check out another branch. Pull never rebases, creates a merge commit or automatically stashes changes.
- Run on Android is part of the task catalog: choose a variant and connected device, then build, install and launch. Requires a configured Android toolchain; no debugger or emulator launch.
- Local MCP access with project sharing and explicit task permissions in Preferences. Agent-started tasks appear in Activity.
- Updated Darsena icon, illustration and interactive story of the harbor, Porta Ticinese, oak and Milanese tram.
- Fixed native path copying and macOS packaging signatures.

## Downloads

Open the **DMG** and drag Darsena into Applications, or extract the **ZIP** for the same app. Quit the existing app before replacing it; settings and saved projects are preserved.

The app is **ad-hoc signed, not Developer ID signed or notarized**. Signature integrity is verified in the app, DMG and ZIP, but macOS Gatekeeper warnings or blocking can still occur for downloaded apps. This release does not remove the need for notarization.

`SHA256SUMS-macos-arm64.txt` verifies the downloads. `build-macos-arm64.json` records the version and exact source commit.

## Validation and scope

GitHub Actions checks types, backend tests and desktop smoke tests against the packaged app, including Git operations, project removal, MCP, Preferences, tasks, worktree navigation and Android deployment with a simulated SDK. Downloads are checked before publication.

Install Git and project toolchains separately. No Windows or Intel Mac installer, Git diff viewer, automatic updater or worktree creation/deletion is included.
